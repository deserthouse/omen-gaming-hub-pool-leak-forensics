## 1. NDIS mandatory 过滤器处置实测（OM-01）

前提：一台可断网、可离线回退的测试机（或有带外管理的备机），先建还原点。

| # | 步骤 | 记录 |
|---|---|---|
| 1 | 基线：`fltmc instances`、`pnputil /enum-drivers`（锁定 rtf64x64.inf 包身份）、绑定适配器清单、网络连通性 | 处置前状态 |
| 2 | `sc config rtf64 start= disabled` → 重启 | 网络是否仍正常；`fltmc` 中过滤器状态 |
| 3 | 若异常：回退（重新 enable + 重启），记录恢复耗时与是否需要离线手段 | 回退可行性 |
| 4 | 可选深入：`pnputil /delete-driver oemNN.inf /uninstall`（按 Original Name+Class 交叉确认后） | 卸载后网络/其它 Realtek 设备是否受影响 |
| 5 | 多 Realtek 包夹具验证选择逻辑（OM-02 关闭条件） | 文档步骤能否唯一选中目标包 |

产出：结果表回填本文档 + docs/05 处置预期更新；失败场景写入文档警告。
